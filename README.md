## Quick guide for testing
 - first step
   - clone repo from my github
   - check .env file and fill up all the necessary variable like PRIVATE_KEY etc.
 - step two
   - check test folder for testing the abstract contract
   - go to Makefile to see the command to test each function in a TestSwapBob.t.sol file
   - see mainnet for command, and run each of them
   - also check TestSwap.sol contract to see how i integrate with the abstract contract.
